# 👗 Martins Ateliê

Sistema web full stack desenvolvido para o **Martins Ateliê**, uma loja de aluguel de vestuário.

O projeto reúne uma vitrine pública para clientes e um sistema administrativo para auxiliar no gerenciamento das atividades da loja.

🌐 **Projeto em implantação:** https://martins-atelie.onrender.com

---

## 📌 Sobre o projeto

O sistema foi desenvolvido para atender às necessidades reais do **Martins Ateliê**, facilitando tanto a apresentação das peças disponíveis aos clientes quanto a organização interna da loja.

A aplicação possui duas áreas principais:

- 🌐 **Vitrine pública**, destinada aos clientes
- 🔐 **Área administrativa**, destinada à gestão do ateliê

O projeto encontra-se em implantação, com o catálogo de peças sendo preparado para publicação.

---

## ✨ Funcionalidades

### 🌐 Área pública

- Vitrine de peças
- Organização por categorias
- Apresentação dos serviços do ateliê
- Contato com a loja
- Integração com WhatsApp

### 🔐 Área administrativa

- Cadastro de clientes
- Cadastro e gerenciamento de peças
- Controle de agendamentos
- Gerenciamento de aluguéis
- Registro de pagamentos
- Controle de despesas
- Painel administrativo
- Acompanhamento financeiro

## 🎯 Objetivo

O objetivo do projeto é digitalizar parte da operação do Martins Ateliê, centralizando informações que antes precisavam ser administradas separadamente e oferecendo uma presença online para apresentação das peças aos clientes.
